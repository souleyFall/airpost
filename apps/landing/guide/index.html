Guide de démarrage · environ 45 minutes

Installe airpost et fais-en ton outil de recherche.

Du clonage du code à ta première lettre prête à relire. Tout est gratuit, tout tourne sur ton ordinateur, et rien n’est envoyé sans que tu l’aies décidé.

0 Avant de commencer

airpost est une application personnelle : un seul compte, installée sur ton ordinateur, qui n’est pas faite pour être mise en ligne. Elle collecte des offres par des API officielles, les note selon ton profil, rédige des lettres avec Gemini (l’IA de Google) et prépare des brouillons Gmail. Elle n’envoie jamais rien toute seule et ne fait aucun scraping de LinkedIn, Indeed ou Welcome to the Jungle.

Il te faut :

  • un ordinateur Windows, macOS ou Linux avec 4 Go de mémoire libre ;
  • une connexion internet et environ 3 Go de disque (Docker et la base de données) ;
  • un compte Google (pour la clé Gemini et, plus tard, Gmail) ;
  • aucune carte bancaire : toutes les formules utilisées sont gratuites, avec des quotas suffisants pour un usage personnel.

Tes données restent chez toi. Ton profil et tes offres sont dans une base PostgreSQL sur ta machine. Seuls les textes nécessaires partent vers Gemini (profil + offre) pour noter et rédiger.

1 Installer les outils

Quatre outils, tous gratuits. Installe-les dans cet ordre :

  1. Git (git-scm.com) pour récupérer le code.
  2. Docker Desktop (docker.com) : il fait tourner la base de données, l’API et l’interface. Lance-le et attends que la baleine soit stable avant de continuer.
  3. Node.js 24 (nodejs.org, version « LTS » ou plus récente que 24).
  4. pnpm, qui s’active avec Node :
corepack enable

Vérifie que tout répond (chaque commande affiche un numéro de version) :

git --version
docker --version
node --version
pnpm --version

Sous Windows, ouvre « PowerShell » ; sous macOS ou Linux, le Terminal. Les commandes de ce guide fonctionnent dans les trois.

2 Récupérer le code

git clone https://github.com/souleyFall/airpost.git
cd airpost
pnpm install

pnpm install télécharge les dépendances (quelques minutes). Toutes les commandes suivantes se lancent depuis ce dossier airpost.

3 Préparer la configuration

Le fichier .env contient tes réglages et tes clés. Il n’est jamais envoyé sur GitHub. Crée-le à partir du modèle : 

cp .env.example .env

Génère ensuite un mot de passe pour la base de données (il s’affiche une seule fois, copie-le) : 

node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"

Ouvre .env dans un éditeur de texte et renseigne ces trois lignes avec ce mot de passe : 

POSTGRES_PASSWORD=le_mot_de_passe_genere
DATABASE_URL=postgresql://airpost:le_mot_de_passe_genere@localhost:5432/airpost

Le mot de passe est le même aux deux endroits. Pour recevoir ta collecte chaque matin à 08 h 30 (heure de Paris), renseigne aussi cette ligne (elle existe déjà, vide, dans le modèle) : 

COLLECT_DAILY_AT=08:30

Docker a besoin que deux fichiers existent à la racine, même vides (Gmail les remplira plus tard). Sans eux, il crée des dossiers à leur place et l’application ne démarre pas correctement : 

node -e "for (const f of ['credentials.json','token.json']) if (!require('fs').existsSync(f)) require('fs').writeFileSync(f, '')"

4 Obtenir les clés gratuites

Colle chaque clé dans .env, sur la ligne qui porte son nom, sans guillemets ni espace. Une source sans clé est simplement désactivée : tu peux commencer avec peu et en ajouter ensuite.

Service Sert à Variables Obligatoire
Gemini (Google AI Studio) Noter les offres, rédiger les lettres et les relances GEMINI_API_KEY Oui
La Bonne Alternance Offres d’alternance officielles LBA_API_KEY Recommandée
France Travail (API La Bonne Boîte) Entreprises qui recrutent FT_CLIENT_ID, FT_CLIENT_SECRET Facultative
Adzuna Annonces agrégées ADZUNA_APP_ID, ADZUNA_APP_KEY Facultative
SerpApi Google Jobs et Glassdoor (250 recherches gratuites par mois) SERPAPI_KEY Facultative

Où les obtenir

  • Gemini : va sur aistudio.google.com, connecte-toi, clique sur « Get API key » puis « Create API key ». La formule gratuite suffit.
  • La Bonne Alternance : labonnealternance.apprentissage.beta.gouv.fr, rubrique pour les développeurs : l’accès à l’API est gratuit sur demande.
  • France Travail : francetravail.io, crée un compte, puis une « application » à laquelle tu ajoutes l’API « La Bonne Boîte » ; tu obtiens un identifiant et un secret.
  • Adzuna : developer.adzuna.com, inscription gratuite.
  • SerpApi : serpapi.com, inscription gratuite.

Ne publie jamais une clé : ni dans un message, ni dans une capture d’écran, ni sur GitHub. Si l’une fuite, révoque-la sur le site du service et recommence.

5 Lancer l’application

Docker Desktop doit être ouvert. Le premier démarrage construit tout (5 à 10 minutes) : 

docker compose up -d --build
docker compose run --rm migrate

La première commande démarre la base, l’API et l’interface. La seconde crée les tables dans la base. Contrôle que les trois services sont « healthy » : 

docker compose ps

6 Créer ton compte

Il n’y a pas d’inscription en ligne, volontairement : le compte se crée depuis ta machine. Choisis un identifiant (lettres, chiffres, point, tiret) puis un mot de passe d’au moins 12 caractères ; il est demandé sans s’afficher. 

pnpm --filter @airpost/api user:create ton_identifiant

Ouvre ensuite http://localhost:8080 et connecte-toi. L’application n’est accessible que depuis ton ordinateur.

7 Remplir ton profil

Dans le menu, ouvre Profil. C’est la seule source de vérité : les lettres ne citent que ce qui s’y trouve, rien n’est inventé.

  • Identité : nom, ville, code postal (pour estimer le trajet). Pas d’adresse complète ni de date de naissance.
  • Formation et expériences, avec des réalisations chiffrées.
  • Compétences : langages, frameworks, outils.
  • Recherche : alternance et/ou stage, rythme accepté, date de début, trajet maximal, mots-clés de ta pile, code ROME (M1805 : développement informatique), entreprises à exclure.

Écris chaque réalisation en trois temps : ce que tu as obtenu, mesuré par un chiffre, en faisant quoi. « Réduit de 40 % le temps d’import (5 min vers 3 min) en ajoutant un cache » vaut mieux que « participé à l’optimisation ».

Un profil complet fait toute la qualité des lettres : prends dix minutes pour le soigner.

8 Première collecte

Clique sur Lancer la collecte dans la barre latérale. Les offres arrivent puis sont notées : la page Sources montre l’état de chaque source (un voyant vert, ou la raison de la panne : clé absente, quota atteint…).

  • La liste d’accueil classe les offres par score, les plus pertinentes en haut.
  • Seules les offres du contrat que tu cherches sont notées par l’IA : les autres restent en fin de liste, non notées.
  • Tu as trouvé une annonce ailleurs ? Bouton + Ajouter une offre : colle le texte, airpost en extrait le poste, l’entreprise et la ville.

Avec COLLECT_DAILY_AT=08:30, la collecte se fait seule chaque matin, tant que l’ordinateur est allumé à cette heure.

9 Brancher Gmail (facultatif)

Sans Gmail, tout fonctionne sauf les brouillons et le suivi des réponses. Avec Gmail, airpost demande deux autorisations seulement : créer des brouillons et lire tes e-mails pour repérer les réponses. Il ne demande jamais celle d’envoyer : il en est incapable.

  1. Va sur console.cloud.google.com et crée un projet (nom libre, par exemple « airpost »).
  2. Dans « API et services », Bibliothèque : cherche « Gmail API » et active-la.
  3. Écran de consentement OAuth : type « Externe », nom « airpost », ton adresse comme contact. À l’étape « Utilisateurs de test », ajoute ta propre adresse Gmail.
  4. Identifiants : « Créer des identifiants », « ID client OAuth », type d’application Application de bureau. Télécharge le fichier JSON.
  5. Renomme-le credentials.json et remplace le fichier vide à la racine du projet.
  6. Lance l’autorisation :
node scripts/gmail-authorize.mjs

Le script affiche un lien : ouvre-le, connecte-toi, accepte les deux autorisations. Google affichera un avertissement « application non vérifiée » : c’est normal, c’est ta propre application ; clique sur « Paramètres avancés » puis « Accéder à airpost ». Le script écrit token.json (le jeton n’est jamais affiché). Redémarre ensuite l’API : 

docker compose up -d --build api

Jeton qui expire au bout de 7 jours ? Tant que l’écran de consentement est en mode « Test », Google invalide le jeton après une semaine. Dans « Écran de consentement », clique sur « Publier l’application » (reste réservée à toi, personne d’autre n’y a accès), puis relance node scripts/gmail-authorize.mjs --force.

Pour recevoir des offres par e-mail, crée des alertes sur Indeed (ou les autres sites qui en proposent) vers cette adresse Gmail : airpost les lit chaque matin.

10 Au quotidien

  1. Offres : parcours la liste, ouvre une offre, lis le score et ses raisons.
  2. Lettre : demande la lettre, relis-la, corrige-la. Les garde-fous refusent les chiffres, les employeurs ou les technologies que ton profil ne contient pas.
  3. Brouillon : valide, et le brouillon apparaît dans ton Gmail, avec ta signature. C’est toi qui cliques sur « Envoyer », dans Gmail.
  4. Suivi : les candidatures avancent selon les réponses détectées. Après 8 jours sans nouvelle, airpost te propose une relance (une seule par candidature), à relire comme une lettre.
  5. Résultats : le tableau de bord mesure ce qui marche (sources, taux de réponse, délais).

11 Mettre à jour, sauvegarder

Pour récupérer les nouveautés du projet :

git pull
pnpm install
docker compose up -d --build
docker compose run --rm migrate

Pour sauvegarder tes données (le fichier est écrit dans backups/, ignoré par Git) : 

pnpm db:backup

Pour tout arrêter sans rien perdre : docker compose down.

? Si ça bloque

« Cannot connect to the Docker daemon »
Docker Desktop n’est pas lancé. Ouvre-le, attends qu’il soit prêt, recommence.
Le port 8080 ou 5432 est déjà utilisé
Un autre programme l’occupe (souvent un PostgreSQL déjà installé). Arrête-le, ou change le port à gauche des deux-points dans docker-compose.yml.
« password authentication failed »
Le mot de passe de .env n’est pas celui avec lequel la base a été créée (la base garde celui du premier lancement). Si tu n’as encore aucune donnée : docker compose down -v (ceci supprime la base) puis relance l’étape 5.
Le mot de passe de ton compte est oublié
Relance pnpm --filter @airpost/api user:create ton_identifiant : il remplace le compte.
Une source est en rouge ou grise
La page Sources dit pourquoi : clé absente ou refusée, quota atteint, service indisponible. Un bandeau rouge en haut de l’écran signale aussi une API en panne.
Gemini répond « quota »
La formule gratuite a une limite par modèle. airpost essaie des modèles de secours ; si tout est saturé, attends quelques minutes ou le lendemain.
Gmail dit « non autorisé » après quelques jours
Voir l’encadré de l’étape 9 : publie l’application puis relance l’autorisation.
Les offres n’arrivent pas à 08 h 30
L’ordinateur était éteint ou en veille, ou COLLECT_DAILY_AT n’est pas dans .env (redémarre ensuite avec docker compose up -d). La collecte manuelle marche toujours.

! Les règles à garder

  • Ne mets jamais sur GitHub : .env, credentials.json, token.json. Ils sont déjà ignorés par Git : ne force rien.
  • N’expose pas l’application sur internet : elle est conçue pour un seul utilisateur, sur ta machine.
  • Ne lui fais pas scraper LinkedIn, Indeed ou Welcome to the Jungle : leurs conditions d’utilisation l’interdisent et ton compte risquerait d’être suspendu.
  • Relis chaque lettre avant d’envoyer : tu signes ce que tu envoies.

Pour comprendre les choix techniques : le fichier docs/decisions.md du dépôt, et SECURITY.md pour la sécurité.
